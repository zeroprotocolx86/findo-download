# Findo — збірки для завантаження

Тут лежать готові файли програми **Findo** для Windows 10 та Windows 11 (64 біти).
Сайт з описом і керівництвом: <https://findo-daps.netlify.app>

Видавець: **DAps — Diachuk Andrii Private Solutions** · diachyk4560@gmail.com

## Поточна версія: 1.4.0

Головне — додано перегляд «За структурою»: папки та файли видно так, як вони лежать насправді.
Цілий диск або флешку більше не треба обирати якимсь окремим способом — система показує їх у
звичному вікні вибору теки, а кілька тек і дисків можна додати в пошук одразу. Ширину колонок тепер
можна тягнути. Детальний опис — на сайті.

| Файл | Розмір | Для кого |
| --- | --- | --- |
| `Findo-Setup-1.4.0-x64.exe` | 168 МБ (176 466 911 байтів) | звичайний комп'ютер: встановлення для свого користувача, ярлики на столі та в «Пусці», деінсталятор у комплекті |
| `Findo-portable-1.4.0-x64.exe` | 8 МБ (8 248 832 байти) | флешка, робочий ПК або разова перевірка теки: запускається подвійним кліком і нічого не встановлює |

Обидва файли зібрано з одного коду, вони працюють без інтернету.

## Місце на диску

- **Інсталятор:** 168 МБ файлу, **близько 500 МБ** на диску після встановлення. Найбільшу частину
  несе власна копія середовища відображення WebView2 — саме тому програма працює на комп'ютері без
  інтернету й без встановленого браузера.
- **Портабл:** 8 МБ, нічого не встановлює; бере системне середовище WebView2, яке є у Windows 11
  і зазвичай у свіжій Windows 10.

Окрім цього росте кеш індексу в `%APPDATA%\Findo\cache\` — він залежить від розміру сканованої
теки й очищується одним кліком у налаштуваннях програми.

## Оновлення поверх старої версії

Не треба нічого видаляти. Завантажте новий файл, відкрийте у програмі «Про програму → Оновити з
файла» і вкажіть на нього: Findo перевірить, що це справді новіша збірка, збереже поточну версію в
`%APPDATA%\Findo\previous\` і запустить нову. Налаштування, нещодавні теки та кеш лишаються на
місці, а повернутися назад можна тим самим вікном. Портабл оновлюється ще простіше — покладіть
новий файл поруч зі старим.

Автоматичних оновлень немає й не буде: програма не виходить у мережу, файл ви приносите самі.

## Перший запуск

Збірки не підписані платним сертифікатом розробника, тому Windows уперше покаже
попередження SmartScreen. Натисніть «Додатково → Все одно запустити». Програма не
потребує прав адміністратора.

## Видалення

- **Інсталятор:** «Параметри → Програми → Findo → Видалити» або деінсталятор у папці
  `%LOCALAPPDATA%\Findo`.
- **Портабл:** приберіть файл і теку `%APPDATA%\Findo`.

Особисті дані (налаштування та кеш індексу) зберігаються в `%APPDATA%\Findo` і
видаляються разом з цією текою.
